Лабораторная работа №1

Последовательное умножение квадратных матриц

В лабораторной работе реализована последовательная программа на C++ для умножения двух квадратных матриц.

Содержание

- `src/main.cpp` — исходный код программы;
- `python/generate.py` — генерация тестовых матриц;
- `python/verify.py` — автоматическая проверка результата с помощью NumPy;
- `results/results.csv` — результаты экспериментов;
- `REPORT.md` — отчёт по лабораторной работе.

Реализованные возможности

Программа:

1. считывает две квадратные матрицы из файлов;
2. выполняет их последовательное умножение;
3. измеряет время вычисления;
4. вычисляет объём выполненных операций;
5. рассчитывает производительность в GFLOPS;
6. сохраняет результирующую матрицу в файл.

Проверка

Корректность результата проверяется независимо с помощью Python и библиотеки NumPy.
