Лабораторная работа №1
Последовательное умножение квадратных матриц

1. Цель работы

Разработать программу на C++, выполняющую последовательное умножение двух квадратных матриц, измерить время выполнения и исследовать зависимость времени вычисления от размера задачи.

Также необходимо выполнить автоматическую проверку результата с помощью независимого программного средства.

2. Постановка задачи

Требуется разработать программу для умножения двух квадратных матриц одинакового размера.

Исходные матрицы считываются из файлов. Результат умножения записывается в выходной файл.

Для каждого запуска необходимо определить:

- размер матриц;
- время выполнения вычисления;
- объём вычислений;
- производительность программы.

3. Теоретические сведения

Для двух квадратных матриц A и B размера N × N элементы результирующей матрицы C вычисляются по формуле:

C[i][j] = sum(A[i][k] * B[k][j])

где k изменяется от 0 до N-1.

Для каждого элемента результирующей матрицы выполняется N умножений и N сложений. Поэтому общий объём вычислений оценивается как:

2 * N^3 операций.

Асимптотическая вычислительная сложность алгоритма составляет:

O(N^3).

4. Реализация

Программа реализована на языке C++.

Для хранения матриц используется `vector<vector<double>>`.

Для измерения времени используется `std::chrono`.

Умножение выполняется последовательным алгоритмом с тремя вложенными циклами. Используется порядок циклов `i-k-j`, позволяющий более эффективно работать с памятью при последовательном доступе к строкам матрицы B.

Время измеряется только для операции умножения матриц, без учёта чтения исходных файлов и записи результата.

Производительность рассчитывается по формуле:

GFLOPS = (2 * N^3) / (T * 10^9),

где N — размер матрицы, а T — время вычисления в секундах.

5. Формат входных данных

В начале каждого входного файла указывается размер матрицы N.

После него записываются N строк по N чисел.

Пример:

3
1 2 3
4 5 6
7 8 9

Используются два входных файла:

- `matrix_a.txt`
- `matrix_b.txt`

Результат записывается в:

- `result.txt`

6. Автоматическая проверка

Для независимой проверки использовался Python и библиотека NumPy.

Результат C++ программы сравнивается с результатом вычисления:

`A @ B`

с помощью функции `numpy.allclose`.

Для тестовых данных проверка завершилась сообщением:

`VERIFICATION PASSED`

Таким образом, результат программы на C++ соответствует результату независимого вычисления средствами NumPy.

8. Анализ результатов

При увеличении размера матриц время выполнения значительно увеличивается.

Например, при увеличении размера матрицы с 1000 до 2000 количество вычислений увеличивается примерно в 8 раз, поскольку сложность алгоритма составляет O(N^3).

Полученные экспериментальные данные подтверждают кубическую зависимость времени выполнения от размера матриц.

Производительность программы во время эксперимента оставалась примерно на одном уровне — около 0.095–0.097 GFLOPS. Это означает, что вычислительная нагрузка увеличивалась пропорционально объёму задачи.

9. Вывод

В ходе лабораторной работы была разработана последовательная программа на C++ для умножения двух квадратных матриц.

Была реализована загрузка исходных данных из файлов, вычисление результирующей матрицы, сохранение результата и измерение времени выполнения.

Было проведено исследование для размеров матриц от 200 × 200 до 2000 × 2000.

Эксперимент подтвердил теоретическую сложность алгоритма O(N^3): при увеличении размера матрицы время выполнения растёт приблизительно пропорционально кубу размера.

Корректность программы была подтверждена независимой автоматической проверкой с использованием Python и NumPy.
